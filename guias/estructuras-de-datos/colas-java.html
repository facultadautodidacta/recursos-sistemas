1. ¿Qué es una Cola (Queue)?

Concepto básico

Imagina una fila del banco. El primero que llegó es el primero que es atendido. Nadie se cuela.

Una cola es una estructura de datos lineal con la regla FIFO (First In, First Out — el primero en entrar es el primero en salir).

La idea en una frase: se inserta por un extremo (el final o rear) y se extrae por el otro (el frente o front).

Ejemplo: si encolas 10 → 20 → 30, el frente es 10. Al desencolar sale el 10, luego el 20, luego el 30.

Operaciones fundamentales

Operación¿Qué hace?
encolar(dato) / enqueueAñade un elemento al final
desencolar() / dequeueSaca y devuelve el elemento del frente
frente() / frontMira el frente sin sacarlo
estaVacia()Indica si no hay elementos
tamaño()Cuántos elementos hay

2. Cola vs Pila: la diferencia clave

AspectoCola (Queue)Pila (Stack)
ReglaFIFO (primero en entrar, primero en salir)LIFO (último en entrar, primero en salir)
Extremos de operaciónDos extremos (frente y final)Solo un extremo (el tope)
Ejemplo realFila del banco, impresoraPila de platos, deshacer (Ctrl+Z)
Usos típicosPlanificación de procesos, BFS, buffersRecursión, evaluación de expresiones, retroceso

3. Ventajas y Desventajas

✅ Ventajas:
  • Operaciones encolar y desencolar en tiempo constante O(1) (con puntero al final).
  • Modela naturalmente problemas donde importa el orden de llegada.
  • Tamaño dinámico si se implementa con nodos.
⚠️ Desventajas:
  • No hay acceso aleatorio: solo puedes ver el frente.
  • Para llegar a un elemento del fondo hay que desencolar los de delante.
  • Si se implementa con array, hay que gestionar el avance circular de índices.

4. Nodo, clase y constructor

Para construir la cola necesitamos un nodo: una caja con un dato y una referencia al siguiente nodo (el que queda detrás en la cola).

4.1 ¿Qué es una clase en Java?

public class Persona {
    String nombre;
    int edad;

    public Persona(String nombre, int edad) {
        this.nombre = nombre;
        this.edad = edad;
    }
}

4.2 ¿Qué es un constructor?

  • Tiene el mismo nombre que la clase.
  • No tiene tipo de retorno.
  • Sirve para dar valores iniciales a los atributos.
  • Si no lo declaras, Java proporciona uno por defecto sin parámetros.

4.3 La clase Nodo auto-referenciada

private static class Nodo {
    int dato;
    Nodo siguiente;

    Nodo(int dato) {
        this.dato = dato;
        this.siguiente = null;
    }
}

Nodo siguiente; guarda una referencia a otro objeto Nodo, no un nodo completo dentro del nodo. La flecha apunta a otra caja o queda vacía (null).

5. Práctica paso a paso en Java

Construiremos una cola enlazada desde cero para entender cómo se conectan sus nodos y cambian sus referencias. En un programa real normalmente conviene usar la interfaz Queue con ArrayDeque.

Estructura del proyecto

Cola.java    ← Gestiona la cola e incluye la clase Nodo
Main.java    ← Crea la cola y prueba sus operaciones

PASO 1: Representar un nodo

private static class Nodo {
    // El valor que almacena este nodo.
    int dato;

    // Referencia al SIGUIENTE nodo de la cola.
    // Si este es el último, 'siguiente' será null.
    Nodo siguiente;

    Nodo(int dato) {
        this.dato = dato;
        this.siguiente = null;
    }
}

PASO 2: Crear la clase Cola

Necesitamos dos referencias: frente para desencolar y fin para encolar en O(1). Sin fin, habría que recorrer la cola para encontrar el último nodo y encolar sería O(n).

public class Cola {

    // 'frente' apunta al PRIMER nodo (por aquí se saca).
    // 'fin'    apunta al ÚLTIMO nodo (por aquí se inserta).
    private Nodo frente;
    private Nodo fin;

    public Cola() {
        this.frente = null;
        this.fin    = null;
    }

PASO 3: Método estaVacia()

public boolean estaVacia() {
    return frente == null;
}

PASO 4: Método encolar(int dato) — O(1)

public void encolar(int dato) {
    Nodo nuevo = new Nodo(dato);

    // Caso 1: cola vacía → el nuevo es frente y fin a la vez.
    if (estaVacia()) {
        frente = nuevo;
        fin    = nuevo;
        return;
    }

    // Caso 2: ya hay elementos → lo enganchamos después del fin.
    fin.siguiente = nuevo;
    fin = nuevo;
}
Traza visual. Cola 10 → 20 → null (frente = 10, fin = 20). encolar(30): Antes: frente → [10|→] → [20|→] → null ↑ fin Paso 1: nuevo = [30|→] Paso 2: fin.siguiente = nuevo ⇒ [20|→] → [30|→] → null Paso 3: fin = nuevo ⇒ fin apunta a [30] Después: frente → [10|→] → [20|→] → [30|→] → null ↑ fin

PASO 5: Método desencolar() — O(1)

Desencolar una cola vacía no tiene un valor que devolver; esta implementación lo indica con IllegalStateException.

public int desencolar() {
    if (estaVacia()) throw new IllegalStateException("La cola está vacía");

    int valor = frente.dato;
    frente = frente.siguiente;   // el segundo pasa a ser el frente

    // Caso especial: si la cola quedó vacía, fin también debe ser null.
    if (frente == null) {
        fin = null;
    }
    return valor;
}
Traza visual. Cola 10 → 20 → 30 → null. desencolar(): Antes: frente → [10|→] → [20|→] → [30|→] → null ↑ fin valor = 10 frente = frente.siguiente ⇒ frente → [20|→] → [30|→] → null Devuelve 10. El nodo [10] queda sin referencias y el GC lo libera.
⚠️ Error común: olvidar fin = null cuando la cola queda vacía. Si no lo haces, fin sigue apuntando a un nodo "fantasma" y el siguiente encolar corrompe la cola.

PASO 6: Métodos verFrente(), tamaño() e imprimir()

public int verFrente() {
    if (estaVacia()) throw new IllegalStateException("La cola está vacía");
    return frente.dato;
}

public int tamaño() {
    int contador = 0;
    Nodo actual = frente;
    while (actual != null) {
        contador++;
        actual = actual.siguiente;
    }
    return contador;
}

public void imprimir() {
    if (estaVacia()) {
        System.out.println("La cola está vacía.");
        return;
    }
    Nodo actual = frente;
    while (actual != null) {
        System.out.print(actual.dato);
        if (actual.siguiente != null) System.out.print(" → ");
        actual = actual.siguiente;
    }
    System.out.println();
}
⚠️ Nunca muevas frente para recorrer. Usa siempre una variable auxiliar Nodo actual = frente;; si no, pierdes la cola.

🧱 Código completo — Cola.java

public class Cola {

    private static class Nodo {
        int dato;
        Nodo siguiente;
        Nodo(int dato) { this.dato = dato; this.siguiente = null; }
    }

    private Nodo frente;
    private Nodo fin;

    public Cola() { this.frente = null; this.fin = null; }

    public boolean estaVacia() { return frente == null; }

    public void encolar(int dato) {
        Nodo nuevo = new Nodo(dato);
        if (estaVacia()) {
            frente = nuevo;
            fin    = nuevo;
            return;
        }
        fin.siguiente = nuevo;
        fin = nuevo;
    }

    public int desencolar() {
        if (estaVacia()) throw new IllegalStateException("La cola está vacía");
        int valor = frente.dato;
        frente = frente.siguiente;
        if (frente == null) fin = null;
        return valor;
    }

    public int verFrente() {
        if (estaVacia()) throw new IllegalStateException("La cola está vacía");
        return frente.dato;
    }

    public int tamaño() {
        int contador = 0;
        Nodo actual = frente;
        while (actual != null) { contador++; actual = actual.siguiente; }
        return contador;
    }

    public void imprimir() {
        if (estaVacia()) { System.out.println("La cola está vacía."); return; }
        Nodo actual = frente;
        while (actual != null) {
            System.out.print(actual.dato);
            if (actual.siguiente != null) System.out.print(" → ");
            actual = actual.siguiente;
        }
        System.out.println();
    }
}

🧪 Pruebas — Main.java

public class Main {
    public static void main(String[] args) {
        Cola cola = new Cola();

        System.out.println("¿Está vacía? " + cola.estaVacia()); // true

        cola.encolar(10);
        cola.encolar(20);
        cola.encolar(30);
        System.out.print("Cola tras encolar 10, 20, 30: ");
        cola.imprimir();                                // 10 → 20 → 30

        System.out.println("verFrente():  " + cola.verFrente());  // 10
        System.out.println("desencolar(): " + cola.desencolar()); // 10
        System.out.print("Cola tras desencolar: ");
        cola.imprimir();                                // 20 → 30

        System.out.println("Tamaño: " + cola.tamaño());        // 2
        System.out.println("desencolar(): " + cola.desencolar()); // 20
        System.out.println("desencolar(): " + cola.desencolar()); // 30
        System.out.println("¿Está vacía? " + cola.estaVacia()); // true
    }
}

6. Complejidades (Notación Big-O)

6.1 ¿Qué es la Notación Big-O?

Es una forma matemática de describir cómo crece el tiempo de ejecución (o el uso de memoria) de un algoritmo a medida que crece el tamaño de la entrada. No mide segundos exactos, sino el orden de magnitud.

  • O(1) → trabajo constante: no aumenta al crecer n.
  • O(n) → trabajo lineal: aumenta en proporción al número de elementos.
  • O(log n) → trabajo logarítmico: crece despacio.
  • O(n²) → trabajo cuadrático: crece rápidamente.

6.2 ¿Qué significa O(1) en una cola?

encolar y desencolar son O(1) porque solo se mueve una referencia. En el caso de encolar, la referencia fin nos ahorra recorrer la cola. Sin ella, encolar sería O(n).

Ejemplo intuitivo: añadir una persona al final de una fila requiere el mismo trabajo tanto si hay 10 personas como si hay 1000.

6.3 Tabla de complejidades de nuestra cola

Operación¿Qué hace?Complejidad¿Por qué?
encolarAñade un elemento al finalO(1)Gracias a la referencia fin, no hay que recorrer.
desencolarSaca el frenteO(1)Solo se mueve frente al siguiente.
verFrenteMira el frenteO(1)Acceso directo a frente.dato.
estaVacia¿Hay elementos?O(1)Solo comprueba frente == null.
tamañoCuenta elementosO(n)Recorre toda la cola.
imprimirMuestra los elementosO(n)Visita cada nodo una vez.
💡 Truco: si guardas un atributo int tamaño y lo incrementas/decrementas en cada operación, tamaño() pasa a O(1).

6.4 Regla práctica para identificar la complejidad

  • ¿El trabajo es siempre el mismo sin importar el tamaño? → O(1)
  • ¿Recorres todos los elementos una vez? → O(n)
  • ¿Recorres todos los elementos y por cada uno haces otro recorrido completo? → O(n²)
  • ¿Vas dividiendo el problema a la mitad en cada paso? → O(log n)

7. Errores Comunes a Evitar

  • Mover frente para recorrer → pierdes la cola entera. Usa siempre Nodo actual = frente;.
  • No comprobar si está vacía antes de desencolar/verFrente → en esta implementación se lanza IllegalStateException.
  • Olvidar fin = null cuando la cola queda vacía → fin apunta a un nodo huérfano y el siguiente encolar se corrompe.
  • En encolar sobre cola vacía, olvidar asignar frente = nuevo → la cola queda inconsistente.
  • Mover frente = frente.siguiente antes de leer el dato en desencolar → pierdes el valor que querías devolver.
  • Confundir actual != null con actual.siguiente != null: el primero recorre todos los nodos, el segundo se detiene en el último.

8. Siguientes Pasos Recomendados

  • Genéricos: cambia int por <T> para colas de cualquier tipo.
  • Cola circular con array: implementa una cola con un arreglo y dos índices (frente, fin) que "den la vuelta" para reutilizar espacio.
  • Cola con dos pilas: ejercicio clásico de entrevistas.
  • Cola de prioridad: usa un heap (montículo) para atender primero los elementos con mayor prioridad.
  • Usar las clases de Java: prueba java.util.ArrayDeque (recomendada) y java.util.LinkedList (implementa Queue).
  • Aplicaciones reales: planificación de procesos, BFS, buffers de impresión, sistemas de mensajería, colas de tareas.
