1. ¿Qué es una Pila (Stack)?

Concepto básico

Imagina una pila de platos. Solo puedes poner un plato arriba y quitar el plato de arriba. No puedes sacar el plato de abajo sin antes quitar todos los de encima.

Una pila es una estructura de datos lineal con una regla muy simple: LIFO (Last In, First Out — el último en entrar es el primero en salir).

La idea en una frase: solo se opera por un extremo (el tope o top). El último elemento que entró es el único al que puedes acceder.

Ejemplo: si apilas 10 → 20 → 30, el tope es 30. Para sacar el 10, primero debes sacar el 30 y luego el 20.

Operaciones fundamentales

Operación¿Qué hace?
push(dato)Apila un elemento arriba
pop()Saca y devuelve el elemento del tope
peek() o top()Mira el tope sin sacarlo
estaVacia()Indica si no hay elementos
tamaño()Cuántos elementos hay

Analogía visual

┌──────┐ │ 30 │ ← tope (último en entrar, primero en salir) ├──────┤ │ 20 │ ├──────┤ │ 10 │ ← base └──────┘

Si haces push(40), queda arriba del 30. Si haces pop(), sale el 40 y vuelve a quedar 30 como tope.

2. Ventajas y Desventajas

✅ Ventajas:
  • Operaciones push y pop en tiempo constante O(1).
  • Modela naturalmente problemas de retroceso (deshacer, recursión, evaluación de expresiones).
  • Tamaño dinámico si se implementa con nodos.
⚠️ Desventajas:
  • No hay acceso aleatorio: solo puedes ver el tope.
  • Para llegar a un elemento del fondo hay que desapilar los de arriba.
  • Si se implementa con un arreglo de tamaño fijo, la capacidad está limitada.

3. Nodo, clase y constructor

Para construir la pila necesitamos un nodo: una caja con un dato y una referencia al siguiente nodo (el que queda debajo).

3.1 ¿Qué es una clase en Java?

Una clase define un tipo de referencia y describe cómo serán los objetos creados a partir de ella. Puede tener atributos, métodos y constructores.

public class Persona {
    String nombre;   // atributo
    int edad;        // atributo

    public Persona(String nombre, int edad) {  // constructor
        this.nombre = nombre;
        this.edad = edad;
    }
}

Persona es un tipo que describe objetos; cuando escribes new Persona("Ana", 25) estás creando un objeto concreto.

3.2 ¿Qué es un constructor?

  • Tiene el mismo nombre que la clase.
  • No tiene tipo de retorno (ni siquiera void).
  • Sirve para dar valores iniciales a los atributos del objeto.
  • Si no declaras ninguno, Java proporciona uno predeterminado sin parámetros.

3.3 ¿Por qué una clase Nodo puede referirse a sí misma?

Al escribir class Nodo { ... } creas el tipo por referencia Nodo. Dentro de la clase puedes declarar Nodo siguiente;: esa variable guarda una referencia a otro objeto Nodo, no un nodo completo dentro del nodo. Este patrón se llama auto-referencia.

private static class Nodo {
    int dato;
    Nodo siguiente;

    Nodo(int dato) {
        this.dato = dato;
        this.siguiente = null;
    }
}
Piensa en cada nodo como una caja con un valor y una flecha. La flecha apunta a otra caja o queda vacía (null); no contiene otra caja dentro.

4. Práctica paso a paso en Java

Construiremos una pila enlazada desde cero para entender cómo se conectan sus nodos y cambia el tope. En programas reales suele preferirse la interfaz Deque con ArrayDeque; Stack es una clase antigua.

Estructura del proyecto

Pila.java    ← Gestiona la pila e incluye la clase Nodo
Main.java    ← Crea la pila y prueba sus operaciones

PASO 1: Representar un nodo

private static class Nodo {
    // El valor que almacena este nodo.
    int dato;

    // Referencia al nodo que queda DEBAJO en la pila.
    // Si este es el último (el fondo), 'siguiente' será null.
    Nodo siguiente;

    Nodo(int dato) {
        this.dato = dato;
        this.siguiente = null;
    }
}
  • int dato; → guarda el valor. Para una pila de Strings sería String dato;.
  • Nodo siguiente; → la "cadena" que une los nodos hacia abajo.
  • El constructor solo pide el dato: un nodo nuevo siempre nace suelto.

PASO 2: Crear la clase Pila

public class Pila {

    // 'tope' apunta al nodo de ARRIBA.
    // Si la pila está vacía, tope == null.
    private Nodo tope;

    public Pila() {
        this.tope = null;
    }

PASO 3: Método estaVacia()

public boolean estaVacia() {
    return tope == null;
}

Si tope es null, no hay ni siquiera un primer nodo: la pila está vacía.

PASO 4: Método push(int dato) — apilar

Es la operación más eficiente de una pila: O(1).

public void push(int dato) {
    // 1) Creamos el nuevo nodo.
    Nodo nuevo = new Nodo(dato);

    // 2) El nuevo nodo apunta al viejo tope (queda "encima").
    nuevo.siguiente = tope;

    // 3) Actualizamos 'tope' al nuevo nodo.
    tope = nuevo;
}
Traza visual. Pila 20 → 10 → null (tope = 20). push(30): Antes: tope → [20|→] → [10|→] → null Paso 1: nuevo = [30|→] Paso 2: nuevo.siguiente = tope ⇒ [30|→] → [20|→] → [10|→] → null Paso 3: tope = nuevo ⇒ tope → [30|→] → [20|→] → [10|→] → null
⚠️ El orden importa: si haces tope = nuevo antes de nuevo.siguiente = tope, pierdes la pila entera.

PASO 5: Método pop() — desapilar

Desapilar una pila vacía no tiene un valor que devolver; esta implementación lo indica con IllegalStateException.

public int pop() {
    if (estaVacia()) {
        throw new IllegalStateException("La pila está vacía");
    }
    int valor = tope.dato;    // guardamos el dato del tope
    tope = tope.siguiente;     // el segundo pasa a ser el nuevo tope
    return valor;
}
Traza visual. Pila 30 → 20 → 10 → null. pop(): Antes: tope → [30|→] → [20|→] → [10|→] → null valor = 30 tope = tope.siguiente ⇒ tope → [20|→] → [10|→] → null Devuelve 30. El nodo [30] queda sin referencias y el GC lo libera.

PASO 6: Métodos peek(), tamaño() e imprimir()

public int peek() {
    if (estaVacia()) throw new IllegalStateException("La pila está vacía");
    return tope.dato;
}

public int tamaño() {
    int contador = 0;
    Nodo actual = tope;
    while (actual != null) {
        contador++;
        actual = actual.siguiente;
    }
    return contador;
}

public void imprimir() {
    if (estaVacia()) {
        System.out.println("La pila está vacía.");
        return;
    }
    Nodo actual = tope;
    while (actual != null) {
        System.out.print(actual.dato);
        if (actual.siguiente != null) System.out.print(" ↓ ");
        actual = actual.siguiente;
    }
    System.out.println();
}
⚠️ Nunca muevas tope para recorrer. Usa siempre una variable auxiliar Nodo actual = tope;; si no, pierdes la pila.

🧱 Código completo — Pila.java

public class Pila {

    private static class Nodo {
        int dato;
        Nodo siguiente;
        Nodo(int dato) { this.dato = dato; this.siguiente = null; }
    }

    private Nodo tope;

    public Pila() { this.tope = null; }

    public boolean estaVacia() { return tope == null; }

    public void push(int dato) {
        Nodo nuevo = new Nodo(dato);
        nuevo.siguiente = tope;
        tope = nuevo;
    }

    public int pop() {
        if (estaVacia()) throw new IllegalStateException("La pila está vacía");
        int valor = tope.dato;
        tope = tope.siguiente;
        return valor;
    }

    public int peek() {
        if (estaVacia()) throw new IllegalStateException("La pila está vacía");
        return tope.dato;
    }

    public int tamaño() {
        int contador = 0;
        Nodo actual = tope;
        while (actual != null) { contador++; actual = actual.siguiente; }
        return contador;
    }

    public void imprimir() {
        if (estaVacia()) { System.out.println("La pila está vacía."); return; }
        Nodo actual = tope;
        while (actual != null) {
            System.out.print(actual.dato);
            if (actual.siguiente != null) System.out.print(" ↓ ");
            actual = actual.siguiente;
        }
        System.out.println();
    }
}

🧪 Pruebas — Main.java

public class Main {
    public static void main(String[] args) {
        Pila pila = new Pila();

        System.out.println("¿Está vacía? " + pila.estaVacia()); // true

        pila.push(10);
        pila.push(20);
        pila.push(30);
        System.out.print("Pila tras push 10, 20, 30: ");
        pila.imprimir();                                 // 30 ↓ 20 ↓ 10

        System.out.println("peek():  " + pila.peek());     // 30
        System.out.println("pop():   " + pila.pop());      // 30
        System.out.print("Pila tras pop: ");
        pila.imprimir();                                 // 20 ↓ 10

        System.out.println("Tamaño: " + pila.tamaño());    // 2
        System.out.println("pop():   " + pila.pop());      // 20
        System.out.println("pop():   " + pila.pop());      // 10
        System.out.println("¿Está vacía? " + pila.estaVacia()); // true
    }
}

5. Complejidades (Notación Big-O)

5.1 ¿Qué es la Notación Big-O?

Es una forma matemática de describir cómo crece el tiempo de ejecución (o el uso de memoria) de un algoritmo a medida que crece el tamaño de la entrada. No mide segundos exactos, sino el orden de magnitud.

  • O(1) → trabajo constante: no aumenta al crecer n.
  • O(n) → trabajo lineal: aumenta en proporción al número de elementos.
  • O(log n) → trabajo logarítmico: crece despacio.
  • O(n²) → trabajo cuadrático: crece rápidamente.

5.2 ¿Qué significa O(1) en una pila?

push y pop son O(1) porque solo hacen un número fijo de operaciones: crear el nodo, mover una referencia y actualizar tope. Nada depende del tamaño de la pila.

Ejemplo intuitivo: sacar el plato de arriba de una torre requiere un movimiento tanto si la torre tiene 10 platos como si tiene 1000.

5.3 Tabla de complejidades de nuestra pila

Operación¿Qué hace?Complejidad¿Por qué?
pushApila un elementoO(1)El nuevo nodo se enlaza con el tope anterior.
popSaca el topeO(1)Solo se mueve tope al siguiente.
peekMira el topeO(1)Acceso directo a tope.dato.
estaVacia¿Hay elementos?O(1)Solo comprueba tope == null.
tamañoCuenta elementosO(n)Recorre toda la pila.
imprimirMuestra los elementosO(n)Visita cada nodo una vez.
💡 Truco: si guardas un atributo int tamaño y lo incrementas/decrementas en cada operación, tamaño() pasa a O(1).

5.4 Regla práctica para identificar la complejidad

  • ¿El trabajo es siempre el mismo sin importar el tamaño? → O(1)
  • ¿Recorres todos los elementos una vez? → O(n)
  • ¿Recorres todos los elementos y por cada uno haces otro recorrido completo? → O(n²)
  • ¿Vas dividiendo el problema a la mitad en cada paso? → O(log n)

6. Errores Comunes a Evitar

  • Mover tope para recorrer → pierdes la pila entera. Usa siempre Nodo actual = tope;.
  • No comprobar si está vacía antes de pop/peek → en esta implementación se lanza IllegalStateException.
  • Mover tope = tope.siguiente antes de leer el dato en pop → pierdes el valor que querías devolver.
  • Mal orden en push: nuevo.siguiente = tope; debe ir antes de tope = nuevo;.
  • Confundir actual != null con actual.siguiente != null: el primero recorre todos los nodos, el segundo se detiene en el último.

7. Siguientes Pasos Recomendados

  • Genéricos: cambia int por <T> para pilas de cualquier tipo.
  • Pila con array: implementa una pila usando un int[] y un índice tope (más rápida y con mejor caché, capacidad fija).
  • Pila que devuelve el mínimo en O(1): ejercicio de entrevistas usando una pila auxiliar.
  • Cola con dos pilas: ejercicio clásico de entrevistas.
  • Usar las clases de Java: prueba java.util.ArrayDeque (recomendada) y java.util.Stack (legacy).
  • Aplicaciones reales: deshacer/rehacer (Ctrl+Z), evaluación de expresiones, recorrido DFS, manejo de llamadas recursivas.
