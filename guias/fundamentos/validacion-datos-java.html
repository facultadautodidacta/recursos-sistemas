Validación de datos en Java con Scanner

Guía rápida con ejemplos prácticos

Entrada correcta = programas más confiables
1 Validar un número entero

Se usa hasNextInt() para verificar si lo que el usuario ingresó puede convertirse en un entero.

import java.util.Scanner;

Scanner teclado = new Scanner(System.in);
int numero;

while (true) {
  System.out.print("Ingresa un número entero: ");
  if (teclado.hasNextInt()) {
    numero = teclado.nextInt();
    break;
  }
  System.out.println("Error: debes ingresar un número entero.");
  teclado.next(); // Descarta la entrada incorrecta
}
System.out.println("Número ingresado: " + numero);
2 Validar un número decimal

Se usa hasNextDouble() para verificar que el dato sea un número decimal.

import java.util.Scanner;

Scanner teclado = new Scanner(System.in);
double numero;

while (true) {
  System.out.print("Ingresa un número decimal: ");
  if (teclado.hasNextDouble()) {
    numero = teclado.nextDouble();
    break;
  }
  System.out.println("Error: debes ingresar un número.");
  teclado.next();
}
System.out.println("Número ingresado: " + numero);
3 Validar un rango de valores

Además de verificar el tipo de dato, se puede validar que el valor esté dentro de un rango. Ejemplo: calificación entre 0 y 100

import java.util.Scanner;
Scanner teclado = new Scanner(System.in);
int calificacion;

while (true) {
  System.out.print("Ingresa una calificación (0-100): ");
  if (teclado.hasNextInt()) {
    calificacion = teclado.nextInt();
    if (calificacion >= 0 && calificacion <= 100) {
      break;
    }
    System.out.println("La calificación debe estar entre 0 y 100.");
  } else {
    System.out.println("Debes ingresar un número entero.");
    teclado.next();
  }
}
System.out.println("Calificación ingresada: " + calificacion);
4 Validar texto (no vacío)

Se puede usar trim() para evitar que el usuario ingrese solo espacios.

import java.util.Scanner;

Scanner teclado = new Scanner(System.in);
String nombre;

System.out.print("Ingresa tu nombre: ");
nombre = teclado.nextLine();

while (nombre.trim().isEmpty()) {
  System.out.println("El nombre no puede estar vacío.");
  System.out.print("Ingresa tu nombre: ");
  nombre = teclado.nextLine();
}
System.out.println("Hola, " + nombre);
5 Validación combinada

Puedes combinar varios tipos de validación en un solo bloque. Ejemplo: un número entero entre 1 y 10.

import java.util.Scanner;
Scanner teclado = new Scanner(System.in);
int numero;

while (true) {
  System.out.print("Ingresa un número entero (1-10): ");
  if (teclado.hasNextInt()) {
    numero = teclado.nextInt();
    if (numero >= 1 && numero <= 10) {
      break;
    }
    System.out.println("El número debe estar entre 1 y 10.");
  } else {
    System.out.println("Debes ingresar un número entero.");
    teclado.next();
  }
}
System.out.println("Número válido: " + numero);
Puntos clave
1
hasNextInt(), hasNextDouble()
Verifican si el dato puede convertirse en el tipo solicitado.
2
nextInt(), nextDouble(), nextLine()
Se usan para leer el dato una vez validado.
3
Siempre usa teclado.next()
Para descartar entradas incorrectas y evitar bucles infinitos.
4
Valida tanto el tipo como el valor
(por ejemplo, un entero entre 1 y 10).
5
trim()
Útil para evitar cadenas vacías o solo espacios.

Consejos finales
  • Usa siempre un bucle (while o do-while) para repetir la entrada en caso de error.
  • Muestra mensajes claros al usuario.
  • Convierte el dato solo después de validarlo.
  • Considera cerrar el scanner al finalizar (teclado.close()).
Una buena validación evita errores, mejora la experiencia del usuario y hace tu programa más robusto.
