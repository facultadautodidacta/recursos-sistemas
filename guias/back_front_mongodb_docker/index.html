Plantilla base

Descarga el esqueleto Docker

Este tutorial parte de una plantilla que organiza Laravel como backend, Angular como frontend y MongoDB como base de datos en servicios de Docker Compose. Incluye los Dockerfiles y la configuración para trabajar con las herramientas dentro de contenedores, sin tener que instalarlas directamente en el equipo.
